# Security policy

## Reporting a vulnerability

If you believe you have found a security vulnerability in a PrivShell module or in this repository, please report it privately.

1. Open the [private vulnerability reporting form](https://github.com/privshell/privshell-repo/security/advisories/new).
2. Describe the issue, the affected module and version, and the steps needed to reproduce it.
3. Include any proof of concept or logs that help us confirm the problem.

Please do not open a public issue for security problems.

## What to expect

- We will acknowledge your report as soon as we can.
- We will investigate, keep you informed of progress and let you know when a fix is available.
- We are happy to credit you in the release notes if you would like.

## Scope

This policy covers:

- The modules listed in this repository
- The repository index in `json/`
- The website served from GitHub Pages

## Safe use of root modules

Root modules run with elevated privileges. Install modules only from sources you trust, review what a module does before installing it, and keep a way to disable modules if your device fails to boot.
