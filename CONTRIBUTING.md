# Contributing

Thank you for helping improve the PrivShell Modules Repo. Bug reports, documentation fixes and pull requests are all welcome.

## Reporting a bug

Use the [bug report form](https://github.com/privshell/privshell-repo/issues/new/choose). A useful report includes:

- The module name and version
- Your root solution (KernelSU, KernelSU Next, APatch or Magisk) and its version
- Your device model and Android version
- What you expected to happen and what happened instead
- Steps to reproduce the problem and any relevant logs

## Suggesting a feature

Open a [feature request](https://github.com/privshell/privshell-repo/issues/new/choose) and describe the problem you want to solve, not only the solution you have in mind.

## Submitting a pull request

1. Fork the repository and create a branch from `master`.
2. Keep each pull request focused on a single change.
3. Update the relevant documentation in `README.md` or `docs/` when behaviour changes.
4. If you edit anything in `json/`, make sure the files are valid JSON. A workflow checks this on every push and pull request.
5. Fill in the pull request template and describe how you tested the change.

## Documentation style

- Write in clear, plain English.
- Use sentence case for headings.
- Keep module names exactly as they appear in the README: **AEGIS // FIREWALL**, **APEX // APPS**, **ORBIT // STORE** and **Git Migrator**.
