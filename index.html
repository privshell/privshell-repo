Install

Up and running in three steps

Add the repository once and every module stays installable and up to date from your module manager.

Add the repository

Open MMRL or a root manager that supports custom repositories and add the repository URL shown above.

Install a module

Pick a module from the list, read its description and tap install. Reboot when your manager asks you to.

Open the WebUI

Launch the module's WebUI from your root manager and configure it to your liking.
